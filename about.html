같이쉼 서비스 안내

같이쉼은 간호사, 경찰, 소방관을 비롯한 교대근무자와 가족·친구가 반복 근무 패턴을 달력으로 확인하고 공동 휴무를 찾도록 돕는 무료 브라우저 도구입니다.

제공 기능

  • 사용자 지정 반복패턴의 월별 달력 표시
  • 두 사람의 패턴 비교와 동시 휴무 표시
  • 월 이동, 공유 링크, 달력 이미지 저장, 인쇄/PDF

계산과 데이터

반복 패턴 계산은 사용자의 브라우저에서 이뤄집니다. 근무표를 서버 계정에 저장하지 않습니다. 링크 공유 기능은 입력값을 URL 쿼리로 담으므로 URL을 전달받은 사람이 패턴을 볼 수 있습니다.

정확성 한계

같이쉼은 입력된 주기가 계속 반복되는 것으로 계산합니다. 기관별 편성, 갑작스러운 변경, 휴가·교육·대체근무는 반영되지 않습니다. 공식 근무표를 대신하지 않습니다.

문의 및 오류 제보

오류나 개선 의견은 GitHub 저장소 이슈 페이지에서 보내 주세요. 개인정보나 상세 근무표가 포함된 내용은 공개 이슈에 게시하지 마세요.
