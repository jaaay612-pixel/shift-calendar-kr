개인정보 및 쿠키 안내

이 페이지는 같이쉼의 현재 동작을 이해하기 위한 안내입니다. 사이트의 기능이나 외부 서비스가 추가되면 내용도 갱신합니다.

입력한 근무 패턴

달력 생성과 비교는 브라우저 안에서 계산합니다. 계정에 로그인하면 날짜별 근무표, 휴무 표기, 표시 이름이 서비스 제공을 위해 Supabase 서버에 저장됩니다. 계정 인증 및 초대 수락 처리를 위해 이메일 주소와 인증 정보가 처리되며, 비밀번호는 Supabase Auth가 관리하고 근무표와 함께 저장되지 않습니다. 데이터 전송은 HTTPS를 사용합니다. 현재 계정 삭제 기능은 제공되지 않습니다. 계정 및 저장 데이터 삭제가 필요하면 GitHub 문의 채널에 요청해 주세요. 계정 삭제는 수동 확인 후 처리해야 할 수 있습니다. 초대받은 사용자는 명시적으로 승인된 일정만 읽을 수 있고 수정 권한이 없습니다.

공유 링크 주의

초대 링크에는 근무표 내용이나 이메일 주소가 포함되지 않습니다. 링크에는 무작위 초대 토큰이 들어가며, 서버에는 원문 대신 토큰 해시만 저장합니다. 초대는 7일 후 만료되고, 정확히 일치하는 확인된 이메일 계정으로 로그인해야 수락할 수 있습니다. 수락한 공유 권한은 30일 후 만료되거나 소유자가 언제든 철회할 수 있습니다. 철회·만료 후에는 새 서버 조회가 차단되지만, 이미 화면에 표시되었거나 저장된 내용까지 회수할 수는 없습니다.

방문 통계

현재 공개 홈페이지에서는 Google Analytics 4 또는 다른 분석 픽셀이 설치된 것을 확인하지 못했습니다. 따라서 본 서비스가 해당 분석 도구를 통해 방문 통계를 수집한다고 안내하지 않습니다. 향후 분석 기능을 추가하면 실제 설정과 수집 항목을 확인한 뒤 이 안내를 갱신하겠습니다.

호스팅 및 외부 서비스

웹사이트는 GitHub Pages에서 제공됩니다. GitHub의 호스팅에 따른 접속 로그 및 쿠키 처리에는 GitHub 정책이 적용될 수 있습니다. 외부 서비스가 추가되면 해당 사업자의 개인정보 안내가 함께 적용될 수 있습니다.

광고

현재 페이지에 Google AdSense 광고는 설치되어 있지 않습니다. 광고를 적용하는 경우 AdSense가 쿠키 또는 유사 기술을 사용할 수 있으므로, 관련 정보와 동의 선택 절차를 이 페이지에 보완할 예정입니다.

문의

개인정보 관련 질문은 GitHub 이슈로 연락할 수 있습니다. 공개 이슈에 민감한 개인정보를 적지 마세요. 현재 전용 비공개 계정 삭제 요청 경로는 아직 설정되지 않았으므로, 민감한 계정 정보를 공개 이슈에 게시하지 마세요. 삭제 요청 시 GitHub 이슈에 계정 이메일 등 민감 정보를 올리지 말고, 비공개로 연락할 경로를 먼저 확인해 주세요.
