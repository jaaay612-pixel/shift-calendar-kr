같이쉼은 날짜별 실제 근무표를 기록하고, 승인된 친구와 모두 함께 쉬는 날이 겹치는지 확인하는 도구예요. 로그인하지 않으면 일정이 이 브라우저 안에 저장되고, 로그인하면 안전하게 서버에 동기화됩니다.

실제 근무표 기록 방법

  1. 달력에서 날짜를 누르고 해당 일의 근무를 입력합니다.
  2. 주간, 야간, 비번 등 원하는 표기를 기록할 수 있습니다.
  3. 이번 달 일괄 입력을 이용해 기본 근무를 채운 뒤 개별 날짜를 수정할 수 있어요.
  4. 로그인한 사람은 초대받아 읽기만 가능한 일정과 날짜별 함께 쉼을 비교할 수 있습니다.

자주 묻는 질문

실제 월 근무표를 날짜별로 기록할 수 있나요?

네. 달력 날짜를 선택해 개별 근무를 입력하고, 월 단위 기본 표기 입력 후 날짜별로 수정할 수 있습니다.

근무표가 지금 서버에 저장되나요?

로그인하지 않으면 이 기기에만 저장되고, 로그인한 일정은 Supabase 서버에 저장됩니다. 공유 일정은 초대받은 사용자만 읽을 수 있어요.

실제 근무표와 달력 결과가 다를 수 있나요?

날짜별로 저장된 실제 근무표를 표시합니다. 병원·기관의 특별 편성이나 변경은 직접 날짜별 입력으로 수정할 수 있지만, 공식 근무표를 최종 기준으로 확인하세요.

같이쉼은 근무일을 직접 배정하거나 기관의 공식 일정과 연동하지 않습니다. 사용자가 직접 기록한 실제 근무표를 달력에 표시하는 도구입니다.

근무표를 확인해 주세요. 로그인한 경우 날짜별 일정은 계정으로 서버에 동기화됩니다. 초대받은 사용자는 승인된 일정만 읽을 수 있습니다.
